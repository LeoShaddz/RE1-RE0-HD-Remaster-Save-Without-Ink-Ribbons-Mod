# Resident Evil / Resident Evil 0 HD Remaster Save Without Ink Ribbons Mod

This mod makes it possible to save the game without needing ink ribbons.

Since ink ribbons become useless with this mod, you can optionally enable a setting in the .ini file that converts any ink ribbons you pick up into green herbs.

Keep in mind that this is optional, if you feel it makes the game too easy, simply leave this option disabled.

# Installation

**RE0**:

1. Install the Ultimate Asi Loader in in the game's root folder
2. Extract the file "RE0.HD.Remaster.Save.Without.Ink.Ribbons.Mod.v1.0.zip"
3. Copy the .asi and .ini files into the "scripts" folder
4. Done

**RE**:

1. Install the Ultimate Asi Loader in in the game's root folder
2. Extract the file "RE.HD.Remaster.Save.Without.Ink.Ribbons.Mod.v1.0.zip"
3. Copy the .asi and .ini files into the "scripts" folder
4. Done
